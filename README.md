# 四足组培训资料

本仓库保存四足组培训计划、任务、配套讲义和练习资源。所有可编辑正文统一使用 Markdown。

## 怎么看这个仓库

培训内容分成两类：

- **任务**：规定本次要做什么、做到什么程度；
- **配套讲义**：解释完成任务需要的知识、提供小例子和排错思路。

如果讲义中的示例与任务的具体要求不一致，**以任务为准**。
