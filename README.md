# 四足组培训资料

本仓库保存四足组培训计划、任务单、配套讲义和练习资源。

## 怎么看这个仓库

培训内容分成两类：

- **任务单**：规定本次要做什么、做到什么程度。任务单保持原始版本，以 PDF 为准。
- **配套讲义**：解释完成任务需要的知识、提供小例子和排错思路。讲义使用 Markdown 维护。

如果讲义中的示例与任务单的具体要求不一致，**以任务单为准**。
