# 第三次培训：关节电机

本阶段从第二次培训的 MuJoCo 机器狗仿真，进入关节控制和单电机实机练习。

## 先读什么

1. [任务.md](./任务.md)：从原任务 PDF 整理出的要求，以及原文待确认之处。
2. [关节电机与控制讲义.md](./关节电机与控制讲义.md)：按新人学习顺序整理的视频与 PDF 内容；含资料核对及实机前待确认条件。
3. [视频 1 文字稿](./01_视频文字稿.md)：力矩源、控制公式、模式和 MuJoCo 仿真，约 18 分钟。
4. [视频 2 文字稿](./02_视频文字稿.md)：减速比、编码器、软件零位和重启后的零位歧义，约 41 分 40 秒。

文字稿是按视频顺序整理的**分段讲解记录**，带时间点，但删去了停顿与重复；它不是逐字速记。讲义把两段视频重排成可独立阅读的材料，任务要求仍以任务书为准。

## 原始材料

- [第三次培训任务 PDF](./6ab87b961b5c3688416fb8bd_第三次培训任务%281%29.pdf)

## 读完后可以自查

- 为什么 `data.ctrl` 在本任务中装的是自己计算的力矩，而不是站立目标角？
- 控制式中的位置、速度、增益和力矩，在仿真关节、输出端、转子侧分别指什么？
- 为什么输出端增益换到转子侧需要除以减速比的平方？
- 软件 `offset` 为什么在反馈和命令两侧方向相反？
- 重启后只知道单圈读数，为什么还不足以确认真实关节零位？

实机控制的型号、反馈语义、限值及异常处理尚需由培训负责人结合队内设备确认；见[任务书待确认项](./任务.md#待培训负责人确认)。
