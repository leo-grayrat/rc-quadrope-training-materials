## 这次要把哪几层接起来

```text
第二次已经会的 MuJoCo
qpos / qvel / ctrl / mj_step
            ↓
关节控制
q / dq / tau / Kp / Kd / tau_ff
            ↓
机械传动
关节输出端 ↔ 减速器 ↔ 电机转子
            ↓
反馈与实机接口
编码器 / 单圈读数 / offset / SDK
            ↓
第三次任务
阻尼状态 / 连续起立 / 实体电机位置控制 / 零点处理
```

读视频时遇到新术语，优先判断它属于上面哪一层。尤其要区分：

- 关节侧与转子侧；
- 控制命令与传感器反馈；
- 物理角度与软件定义的零位坐标。

这三个区分建立以后，第二段视频里最密集的减速比和零位内容会清楚很多。
