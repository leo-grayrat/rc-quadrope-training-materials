# 第三次培训：关节电机、控制与实机接口

这一阶段承接第二次的 MuJoCo 仿真，开始把仿真中的关节状态和控制量对应到真实四足机器人的关节电机、减速器、编码器和 SDK。

正文已经把原视频讲解、`motor.pdf` 中的内容和完成任务所需的代码连接揉在一起。视频截图保留在对应知识点附近，原始 PDF 继续留档。

## 学习顺序

1. [关节电机与关节控制](./01_关节电机与关节控制.md)
2. [减速器、编码器与关节坐标](./02_减速器编码器与关节坐标.md)
3. [第三次任务实现](./03_第三次任务实现.md)

第一篇从第二次已经会的 `qpos / qvel / ctrl` 出发，补上力矩、PD、阻尼和 MuJoCo `<motor>` 的控制链。

第二篇展开真实关节里此前被仿真模型压缩掉的机械和传感器层：转子、减速器、输出端、单圈编码器、软件零位，以及这些量怎样在代码里换算。

第三篇把前两篇落到本次任务：仿真中的阻尼与连续起立状态机，以及实机 SDK、缓慢回零、键盘目标、软件零位和单圈跳变处理。
