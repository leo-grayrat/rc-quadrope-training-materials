# 第三次培训任务

> 整理自原始《第三次培训任务》PDF。本文保留原任务的要求；原文中需要确认的表述列在文末。实际验收要求如有变化，应由培训负责人确认后更新。

本次任务分为仿真和实体电机控制两部分。

## 一、仿真部分

在已有仿真程序中加入关节电机控制程序，并将控制程序写成至少包含以下两个状态的状态机：

1. **阻尼模式**：所有关节电机处于阻尼状态。
2. **站立模式**：在阻尼模式下按某个键，机器狗从当前初始姿态连续地站起来；按另一个键，切换回阻尼模式。原任务要求“从任意初始位置，差值，连续地站起来”，其中“差值”一词待确认。

## 二、实体电机控制

1. 使用宇树官方电机 SDK 例程，先尝试让电机转起来。
2. 编写控制程序：让电机缓慢回到 0 位置；随后从键盘输入一个角度，让输出端缓慢转到该角度。
3. 用记号笔或贴纸标记第 2 步的零点。按照课程视频讲解的方法将零点向正方向偏移 30°，再次让电机转到第 2 步指定的角度，对照实际角度与终端报告的位置是否符合预期。原任务提醒：上电前应自行确认零点没有跳变；也可以先完成第 4 步，再做本步。
4. 在第 3 步的基础上，尝试用课程视频讲解的方法处理零点跳变。分别把输出端手动转到第 2 步零点的两侧附近，再让电机转到第 3 步的位置，观察是否发生跳变。

**原任务的实机要求：**提前做好保护，使用插值让电机缓慢转动；使用大疆电池。接线不熟悉时请求四足组或电控组老队员帮助。

## 待培训负责人确认

- 仿真任务中的“差值”是否应为“插值”；若是，起立过程的时长、插值对象和完成判据是什么？
- “任意初始位置”是否有姿态或关节范围限制？阻尼模式切回后，站立目标与当前状态如何衔接？
- 实机任务里“回到 0 位置”及“正向偏移 30°”分别以转子侧还是输出端角度定义？键盘输入的角度使用什么单位和参考零点？
- 第 4 步中“第 3 步的位置”究竟指偏移后的零点，还是第 2 步指定的目标角？原文两种表述并存。
- 如何判定“零点未跳变”“符合预期”和“发生跳变”？现场保护和停止条件由谁确认？
