# 第四次培训：ROS2 与控制/执行解耦

这一阶段承接第三次已经能工作的控制程序。第三次里，读取状态、计算控制量、把控制量送进 MuJoCo 或电机 SDK 往往还写在同一个程序里；第四次要做的事情，是把这些职责拆成可以独立运行、通过明确接口交换数据的程序。

本次不追求“把 ROS2 所有概念过一遍”。完成后应该能够：

- 分清工作空间、功能包、可执行程序和节点分别属于哪一层；
- 建立并运行一个最小 C++ ROS2 节点；
- 用话题连接控制器和执行端，并明确消息里的单位、顺序和含义；
- 用 ROS2 命令观察节点、话题、消息和频率；
- 把第三次的控制逻辑与 MuJoCo 执行循环拆开；
- 用参数和 launch 管理启动时配置与多节点启动；
- 知道话题和服务解决的是不同交互问题，而不是把服务理解成“不会丢消息的话题”。
