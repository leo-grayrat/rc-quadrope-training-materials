# 第四次培训：ROS2 与控制/执行解耦

这一阶段承接第三次已经能工作的控制程序。第三次里，读取状态、计算控制量、把控制量送进 MuJoCo 往往还写在同一个程序里；第四次把这些职责拆成独立运行、通过明确接口交换数据的程序。

完成后应该能够：

- 分清工作空间、功能包、可执行程序和节点分别属于哪一层；
- 建立并运行一个最小 C++ ROS2 节点；
- 用话题连接控制器和 MuJoCo 执行端，并明确消息里的单位、顺序和含义；
- 用 ROS2 命令观察节点、话题、消息和频率；
- 把第三次的控制逻辑与 MuJoCo 执行循环拆开；
- 把第三次 Python 控制数学逐步迁移到 C++，并用本地测试独立验算；
- 用参数和 launch 管理启动配置与多节点启动；
- 根据交互方式区分话题、服务和参数。

前两篇建立 ROS2 程序的组织和运行模型；第三篇用一个关节跑通“状态消息 → 控制器 → 力矩消息”，再扩到 12 个关节；第四篇回到第三次 MuJoCo 程序完成进程拆分；第五篇单独迁移控制逻辑并用 C++ 本地测试验算；最后用参数和 launch 组织完整控制链。
