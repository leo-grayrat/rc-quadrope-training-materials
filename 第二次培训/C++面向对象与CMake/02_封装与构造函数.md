# 封装与构造函数

上一节中，`Motor` 的成员变量都是公开的：

```cpp
motor1.position = 100000.0;
```

这种写法允许类外代码直接修改对象状态。如果程序希望把电机位置限制在 `[-3.14, 3.14]`，公开的 `position` 就无法保证这个约束，因为任何地方都可以绕过检查直接赋值。

## public 与 private

类成员可以设置访问权限：

```cpp
class Motor {
public:
    // 类外可以访问

private:
    // 只能由类自己的成员函数访问
};
```

把 `position` 设为 `private` 后，类外代码不能再直接写：

```cpp
motor.position = 1.0;
```

如果希望外部仍然能够设置位置，可以提供成员函数：

```cpp
motor.setPosition(1.0);
```

这样，所有位置修改都会经过 `setPosition()`。限位检查、错误处理、使能状态检查等逻辑都可以集中放在这里。

这种做法通常称为**封装**：对象内部状态由类自己维护，外部通过公开接口使用对象。

## 构造函数

上一节创建对象以后，还需要分别给成员变量赋值：

```cpp
Motor motor;
motor.id = 3;
motor.position = 0.0;
```

如果一个 `Motor` 对象必须有编号，并且初始位置统一为 `0.0`，可以在创建对象时直接完成初始化。

构造函数与类同名，没有返回类型：

```cpp
Motor(int id)
{
    // 初始化
}
```

使用时：

```cpp
Motor motor(3);
```

构造函数会在对象创建时自动执行。

### 成员初始化列表

C++ 中常用成员初始化列表初始化成员：

```cpp
Motor(int id)
    : id_(id), position_(0.0)
{
}
```

`id_(id)` 表示使用构造函数参数 `id` 初始化成员 `id_`，`position_(0.0)` 表示把初始位置设为 `0.0`。

它和在构造函数体中重新赋值并不完全相同。成员会先完成初始化，再进入构造函数体。引用成员和 `const` 成员必须通过初始化列表初始化，因此养成使用初始化列表的习惯会更方便。

成员的实际初始化顺序由**类中成员的声明顺序**决定。例如：

```cpp
class Motor {
private:
    int id_;
    double position_;
};
```

这里一定先初始化 `id_`，再初始化 `position_`。初始化列表最好也按相同顺序书写。

## const 成员函数

有些成员函数只读取对象状态。例如：

```cpp
double getPosition() const
{
    return position_;
}
```

函数参数列表后的 `const` 表示这个函数不会修改当前对象的普通成员变量。

下面的写法会报错：

```cpp
double getPosition() const
{
    position_ = 1.0;
    return position_;
}
```

对于 getter、状态打印等只读操作，通常应当加上这个 `const`。

## explicit

如果类有单参数构造函数：

```cpp
Motor(int id);
```

C++ 可能允许下面这种隐式转换：

```cpp
Motor motor = 3;
```

编译器会把整数 `3` 当作 `Motor(3)`。

这里的整数只是电机编号，没有必要允许这种隐式转换，因此可以写：

```cpp
explicit Motor(int id);
```

这样创建对象时需要明确写出：

```cpp
Motor motor(3);
```

<summary>参考实现</summary>

```cpp
class Motor {
private:
    int id_;
    double position_;

public:
    explicit Motor(int id)
        : id_(id), position_(0.0)
    {
    }

    bool setPosition(double position)
    {
        if (position < -3.14 || position > 3.14) {
            return false;
        }

        position_ = position;
        return true;
    }

    double getPosition() const
    {
        return position_;
    }

    void printStatus() const
    {
        std::cout << "Motor " << id_ << " position: "
                  << std::fixed << std::setprecision(2)
                  << position_ << " rad" << std::endl;
    }
};
```
