# 基础与类对象

## 从一个最小 C++ 程序开始

先建立一个练习目录：

```bash
mkdir -p ~/robot_cpp_training/oop_cmake
cd ~/robot_cpp_training/oop_cmake
```

创建 `hello.cpp`：

```cpp
#include <iostream>

int main()
{
    std::cout << "Hello Robot Team!" << std::endl;
    return 0;
}
```

编译并运行：

```bash
g++ hello.cpp -std=c++17 -o hello
./hello
```

第一条命令把 `hello.cpp` 编译、链接成可执行文件 `hello`；第二条命令运行当前目录下的这个文件。

如果运行时出现：

```text
./hello: No such file or directory
```

先检查当前目录和编译结果：

```bash
pwd
ls
```

确认 `hello` 是否真的生成，以及当前终端是否位于正确目录。后面做多文件工程时也经常需要先排除这类路径问题。

`std::cout`、`std::string` 前面的 `std::` 表示它们位于标准库的 `std` 命名空间中。后面的代码也保持这种写法，便于直接看出名称来自哪个命名空间。

## 类与对象

假设程序现在要保存两台电机的编号和位置：

```cpp
int motor1_id = 1;
double motor1_position = 0.0;

int motor2_id = 2;
double motor2_position = 0.5;
```

如果以后继续增加速度、力矩、温度等数据，就会出现很多彼此平行的变量：

```text
motor1_id
motor1_position
motor1_velocity
motor1_torque
motor1_temperature

motor2_id
motor2_position
...
```

这些变量实际上都属于某一台电机。C++ 可以用 `class` 定义一个 `Motor` 类型，把同一台电机的数据和操作放在一起：

```cpp
class Motor {
    // 电机相关的数据和操作
};
```

有了这个类型以后，可以创建多个对象：

```cpp
Motor motor1;
Motor motor2;
```

`Motor` 是类型，`motor1` 和 `motor2` 是这个类型的两个对象。每个对象都有自己的一份成员数据。

类中定义的变量称为**成员变量**，类中定义的函数称为**成员函数**。例如可以把电机编号、位置作为成员变量，把打印状态写成成员函数。

## 动手：补全最基础的 Motor

这一节只练习类、对象、成员变量和成员函数。

要求：

- 定义一个 `Motor` 类；
- 每个对象保存整数编号 `id`；
- 每个对象保存当前位置 `position`，单位为 rad；
- 这一节先把两个成员设为 `public`；
- 提供 `printStatus()`，按下面格式输出状态：

```text
Motor 1 position: 0.00 rad
```

起始代码：

- [starter/01_motor/main.cpp](./starter/01_motor/main.cpp)

`main()` 已经给好，只补 `Motor`。

预期输出：

```text
Motor 1 position: 0.00 rad
Motor 2 position: 0.50 rad
```

<details>
<summary>参考实现</summary>
<pre><code class="language-cpp">class Motor {
public:
    int id;
    double position;

    void printStatus() const
    {
        std::cout &lt;&lt; "Motor " &lt;&lt; id &lt;&lt; " position: "
                  &lt;&lt; std::fixed &lt;&lt; std::setprecision(2)
                  &lt;&lt; position &lt;&lt; " rad" &lt;&lt; std::endl;
    }
};</code></pre>
<p><code>std::fixed</code> 与 <code>std::setprecision(2)</code> 用于固定显示两位小数。<code>printStatus()</code> 后面的 <code>const</code> 会在下一节介绍。</p>
</details>
