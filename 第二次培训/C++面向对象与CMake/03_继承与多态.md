# 继承与多态

前面的 `Motor` 只有一种实现。实际机器人可能同时使用不同型号的电机，例如 DM 电机和 Unitree 电机。它们底层通信方式不同，但上层控制通常都需要类似的操作：

```text
enable()
setPosition(position)
getPosition()
```

如果控制代码直接依赖具体型号，就会出现大量分支：

```cpp
if (type == DM) {
    ...
} else if (type == UNITREE) {
    ...
}
```

电机型号增加以后，这些判断会散落到很多地方。可以先定义一套统一接口，让上层只和这套接口交互。

## 抽象类与纯虚函数

这里定义一个 `Motor` 基类：

```cpp
class Motor {
public:
    virtual void enable() = 0;
    virtual void setPosition(double position) = 0;
    virtual double getPosition() const = 0;
    virtual ~Motor() = default;
};
```

`= 0` 表示纯虚函数。包含纯虚函数的类属于抽象类，不能直接创建对象：

```cpp
Motor motor;  // 编译错误
```

这里的 `Motor` 规定了电机对象需要提供的三个操作。具体型号负责实现这些函数。

最后一行：

```cpp
virtual ~Motor() = default;
```

定义了虚析构函数。以后如果通过 `Motor*` 删除派生类对象，虚析构可以保证派生类析构函数正常执行。当前练习没有动态分配对象，但基类既然用于多态，就把析构函数一并定义好。

## 继承与 override

DM 电机可以写成：

```cpp
class DMMotor : public Motor {
public:
    void enable() override;
    void setPosition(double position) override;
    double getPosition() const override;
};
```

`public Motor` 表示 `DMMotor` 继承 `Motor` 的公开接口。

`override` 用来让编译器检查当前函数是否真的覆盖了基类虚函数。例如把：

```cpp
double getPosition() const override;
```

误写成：

```cpp
double getPosition() override;
```

少了 `const`，编译器会直接报错。

Unitree 电机也可以继承同一个 `Motor` 接口。这样两个具体类的实现不同，但对外提供相同的调用方式。

## 多态与基类引用

下面这个函数接收 `Motor&`：

```cpp
void controlMotor(Motor& motor)
{
    motor.enable();
    motor.setPosition(1.5);
}
```

调用时可以传入不同派生类对象：

```cpp
DMMotor dm(1);
UnitreeMotor unitree(2);

controlMotor(dm);
controlMotor(unitree);
```

`Motor&` 可以引用派生类对象。调用虚函数时，程序会根据实际对象类型选择对应实现：

- 传入 `DMMotor`，调用 `DMMotor::enable()`；
- 传入 `UnitreeMotor`，调用 `UnitreeMotor::enable()`。

这就是这里使用到的运行时多态。

这里使用引用还有一个直接好处：函数操作现有对象，不会额外复制一份电机对象。

## 动手：实现两种具体电机

- [starter/03_polymorphism/main.cpp](./starter/03_polymorphism/main.cpp)

实现 `DMMotor` 和 `UnitreeMotor`。

要求：

- 两个类都保存自己的 `id` 和 `position`；
- 初始位置为 `0.0`；
- `enable()` 输出：
  - `DM Motor <id> enabled.`
  - `Unitree Motor <id> enabled.`
- `setPosition(x)` 保存位置，并分别输出：
  - `DM Motor <id> -> target = <x> rad`
  - `Unitree Motor <id> -> target = <x> rad`
- 位置统一显示两位小数；
- `getPosition()` 返回当前保存的位置。

预期输出：

```text
DM Motor 1 enabled.
DM Motor 1 -> target = 1.50 rad
Unitree Motor 2 enabled.
Unitree Motor 2 -> target = 1.50 rad
```

<summary>参考实现</summary>

```cpp
class DMMotor : public Motor {
public:
    explicit DMMotor(int id)
        : id_(id), position_(0.0)
    {
    }

    void enable() override
    {
        std::cout << "DM Motor " << id_ << " enabled." << std::endl;
    }

    void setPosition(double position) override
    {
        position_ = position;
        std::cout << "DM Motor " << id_ << " -> target = "
                  << std::fixed << std::setprecision(2)
                  << position_ << " rad" << std::endl;
    }

    double getPosition() const override
    {
        return position_;
    }

private:
    int id_;
    double position_;
};

class UnitreeMotor : public Motor {
public:
    explicit UnitreeMotor(int id)
        : id_(id), position_(0.0)
    {
    }

    void enable() override
    {
        std::cout << "Unitree Motor " << id_ << " enabled." << std::endl;
    }

    void setPosition(double position) override
    {
        position_ = position;
        std::cout << "Unitree Motor " << id_ << " -> target = "
                  << std::fixed << std::setprecision(2)
                  << position_ << " rad" << std::endl;
    }

    double getPosition() const override
    {
        return position_;
    }

private:
    int id_;
    double position_;
};
```
