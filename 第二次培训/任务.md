# c++/python 概念-任务

> （务必不要让 ai 一键生成，尽量手写，ai 可以提供意见但不能代替你做任务，学习阶段和工作阶段 ai 扮演的角色是不同的）

1. 安装并了解 mujoco 软件，包括软件的作用之类的。

2. 使用 python 语言，将机器人 urdf 文件导入 mujoco（urdf 文件请在 github 搜索 N-W-wolf 并在 User 中找到组织，然后找到文件），并且编写代码运行仿真。（提示：urdf 不能直接导入 mujoco，需要转换成 mjcf，请务必从 urdf 自行转换，另外额外要求弄清楚怎么在mujoco中加载场景，尝试加载一个平坦的地形，然后让狗静止趴在场景中。urdf 转 mjcf 可以在 https://urdf.enkeebot.com/zh/ 网站完成，此网站亦可预览 urdf/mjcf 等模型文件。另外此任务机器狗可以不动）。另外要求定义关节驱动器类型为力矩模式。 达到让机器狗静止趴在平坦地面上即视为任务完成。（关节输出力矩为0即可）

3. 网络上查找 unitree_mujoco 代码并学习，进一步优化自己的仿真运行代码，考虑你代码的结构，线程等设计是否足够优秀。

4. （选做）使用 cpp 重新完成上述任务。
