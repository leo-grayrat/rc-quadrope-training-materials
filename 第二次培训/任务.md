# 第二次培训任务：C++ / Python 概念与 MuJoCo

> 务必不要让 AI 一键生成，尽量手写。AI 可以提供意见但不能代替你做任务，学习阶段和工作阶段 AI 扮演的角色是不同的。

1. 安装并了解 MuJoCo 软件，包括软件的作用之类的。

2. 使用 Python 语言，将机器人 URDF 文件导入 MuJoCo（URDF 文件请在 GitHub 搜索 N-W-wolf 并在 User 中找到组织，然后找到文件），并且编写代码运行仿真。

   提示：URDF 不能直接导入 MuJoCo，需要转换成 MJCF，请务必从 URDF 自行转换。另外额外要求弄清楚怎么在 MuJoCo 中加载场景，尝试加载一个平坦的地形，然后让狗静止趴在场景中。URDF 转 MJCF 可以在 <https://urdf.enkeebot.com/zh/> 网站完成，此网站亦可预览 URDF / MJCF 等模型文件。

   另外，此任务机器狗可以不动。要求定义关节驱动器类型为力矩模式。达到让机器狗静止趴在平坦地面上即视为任务完成。（关节输出力矩为 0 即可。）

3. 网络上查找 `unitree_mujoco` 代码并学习，进一步优化自己的仿真运行代码，考虑你代码的结构、线程等设计是否足够优秀。

4. （选做）使用 C++ 重新完成上述任务。
