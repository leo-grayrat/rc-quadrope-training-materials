# MuJoCo 与机器人仿真基础

这一部分面向第二次培训中的 MuJoCo 任务。默认已经完成第一次培训和 C++ 面向对象部分，不要求提前学过 Python 或机器人动力学。

## 学习顺序

1. [Python 基础](./01_Python基础.md)
2. [入门与最小仿真](./02_入门与最小仿真.md)
3. [MJCF 与机器人模型](./03_MJCF与机器人模型.md)
4. [状态、执行器与控制](./04_状态执行器与控制.md)
5. [机器狗任务实现](./05_机器狗任务实现.md)
6. [工程组织与 unitree_mujoco](./06_工程组织与unitree_mujoco.md)
7. [排错与后续](./07_排错与后续.md)

前四篇补足读懂和编写 MuJoCo Python 程序需要的知识。第五篇对应正式任务，把前面的内容连成完整实现过程。第六篇在任务完成后再讨论代码结构和线程。
