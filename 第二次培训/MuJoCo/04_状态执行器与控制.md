# 状态、执行器与控制

## qpos、qvel、ctrl

运行中的主要数据放在 `MjData` 中：

- `qpos`：当前位置状态；
- `qvel`：当前速度状态；
- `ctrl`：执行器控制输入；
- `time`：仿真时间。

对于自由基座四足机器人，`qpos` 前 7 个位置通常属于基座，后面才是腿部关节。实际数组结构以模型定义为准，电机数量本身不能确定 `qpos` 的排列。

## joint 与 actuator

`joint` 只说明这个地方可以怎样运动。要通过 `data.ctrl` 对关节施加控制，还需要 actuator。

培训任务要求力矩模式，使用 `motor` actuator：

```xml
<actuator>
    <motor name="joint1_motor" joint="joint1" gear="1"/>
</actuator>
```

这里：

- `name`：actuator 名称；
- `joint`：它作用的关节；
- `gear`：传动比例。

`motor` 是 MuJoCo 的直接驱动 actuator。对于本任务这种一对一 hinge joint，可把 `data.ctrl` 中对应输入理解为直接驱动量。

## 查找关节

模型中的对象都有内部编号。根据 XML 中的名字查 joint：

```python
joint_id = mujoco.mj_name2id(
    model,
    mujoco.mjtObj.mjOBJ_JOINT,
    "FL_hip_joint",
)
```

`mj_name2id(model, type, name)` 返回指定对象的内部 id。

joint 相关的常用 `MjModel` 成员：

- `njnt`：joint 数量；
- `jnt_qposadr[id]`：这个 joint 在 `qpos` 中的起始下标；
- `jnt_dofadr[id]`：这个 joint 在 `qvel` 中的起始下标。

例如：

```python
qpos_adr = model.jnt_qposadr[joint_id]
print(qpos_adr)
```

### 练习：找到一个关节的位置

从自己的 MJCF 中选一个 hinge joint，例如 `FL_hip_joint`。

要求：

1. 用 `mj_name2id()` 得到 joint id；
2. 输出 joint id；
3. 输出它的 `qpos` 起始下标；
4. 输出当前关节位置 `data.qpos[qpos_adr]`。

输出格式：

```text
joint id: <整数>
qpos address: <整数>
position: <浮点数>
```

具体数字由模型决定。

## 修改状态

可以直接修改 `qpos`：

```python
data.qpos[qpos_adr] = 0.5
```

手工修改状态后，可以调用：

```python
mujoco.mj_forward(model, data)
```

让 MuJoCo 根据当前状态重新计算相关量，但不推进仿真时间。

## 写入控制输入

全部执行器设为 0：

```python
data.ctrl[:] = 0.0
```

单独设置第 1 个控制输入：

```python
data.ctrl[0] = 1.0
```

`model.nu` 是 `ctrl` 的长度。当前任务使用普通单输入 motor actuator 时，通常与 actuator 数量一致。

### 练习：检查 actuator

加入 motor actuator 后，输出：

```python
print(model.nu)
print(data.ctrl)
```

如果机器狗有 12 个单输入驱动关节，预期 `model.nu` 为 12，`data.ctrl` 初始应为 12 个 0。

实际数量仍以自己的模型为准。

## Viewer 中运行

运行循环的核心顺序是：

```python
while viewer.is_running():
    # 读取 data

    # 修改 data.ctrl

    mujoco.mj_step(model, data)
    viewer.sync()
```

这里已经可以把前面的内容连起来：读取状态、写控制输入、推进一步、更新显示。
