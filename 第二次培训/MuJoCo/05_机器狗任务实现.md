# 机器狗任务实现

前面已经分别完成了模型加载、场景、状态读取和执行器配置。现在把它们连成第二次培训要求的程序。

## 最终程序要完成什么

需要自己写一个 Python 仿真程序，满足：

1. 加载包含机器人和平地的 MJCF 场景；
2. 创建 `MjData`；
3. 设置机器狗的初始 base 高度；
4. 设置各驱动关节的初始角，使机器人处于合理趴卧姿态；
5. 调用 `mj_forward()` 更新初始状态；
6. 所有执行器输入保持为 0；
7. 在 Viewer 中不断调用 `mj_step()` 运行仿真。

成功时应看到：

- 机器人位于平坦地面上；
- 初始状态没有明显穿地；
- 运行后没有持续弹飞或剧烈抖动；
- 经过短暂运动后整体趋于静止；
- `data.ctrl` 始终为 0。

## 第一步：检查转换结果

先单独打开机器人 MJCF：

```bash
python3 -m mujoco.viewer --mjcf=path/to/robot.xml
```

检查：

- mesh 是否完整；
- 四条腿是否在正确位置；
- joint 的方向和范围是否合理；
- base 是否有 free joint；
- 有没有明显的初始穿模。

此时有问题就先改模型，不进入仿真程序。

## 第二步：建立平地场景

使用上一节完成的 `flat_scene.xml`。

Viewer 中应同时看到机器人和地面。

## 第三步：配置并检查 actuator

每个驱动 joint 对应一个 motor actuator。

加载场景后检查：

```python
print(model.nu)
print(data.ctrl)
```

12 个独立单输入执行器时，`nu` 应为 12。

还要回到 MJCF 核对每个 actuator 的 `joint="..."`，确认没有漏掉或接错关节。

## 第四步：设置趴卧姿态

初始姿态由：

- base 的位置和姿态；
- 12 个腿部 joint 的角度

共同决定。

根据上一节的方法，用 joint 名称找到它在 `qpos` 中的位置，再写入初始角度。

具体角度由实际机器人模型决定。调试时一次只调整少量关节，并在 Viewer 中观察：

- 左右腿方向是否正确；
- 小腿是否折向预期方向；
- 机身是否离地过高或已经穿地。

设置完成以后调用：

```python
mujoco.mj_forward(model, data)
```

此时 Viewer 中应该已经能看到准备开始仿真的初始姿态。

## 第五步：零力矩运行

进入循环前和循环中都保持：

```python
data.ctrl[:] = 0.0
```

循环继续执行：

```python
mujoco.mj_step(model, data)
viewer.sync()
```

这里不加入 PD 或姿态保持控制器，因为任务要求关节输出力矩为 0。

## 验证

除了看 Viewer，还可以观察：

```python
print(data.qvel)
```

稳定以后，速度应逐渐变小。

如果模型持续滑动、抖动或弹飞，再进入 [排错与后续](./07_排错与后续.md) 按模型、初始状态和接触参数逐层检查。
