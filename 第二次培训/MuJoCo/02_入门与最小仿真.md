# 入门与最小仿真

## MuJoCo 做什么

MuJoCo 根据机器人模型、当前状态和控制输入计算下一时刻的运动状态。

```text
模型 + 当前状态 + 控制输入
            ↓
          MuJoCo
            ↓
         下一状态
```

当前阶段先掌握三件事：加载模型、保存运行状态、推进仿真。

## MjModel 与 MjData

MuJoCo 用 `MjModel` 保存模型结构和固定参数，例如刚体、关节、质量、执行器和仿真参数。

从 MJCF 文件加载模型：

```python
model = mujoco.MjModel.from_xml_path("scene.xml")
```

`MjData` 保存运行中的状态：

```python
data = mujoco.MjData(model)
```

常用成员：

`MjModel`：

- `nq`：`qpos` 长度；
- `nv`：`qvel` 长度；
- `nu`：控制输入 `ctrl` 的长度；
- `opt.timestep`：一个仿真步对应的时间。

`MjData`：

- `qpos`：位置状态；
- `qvel`：速度状态；
- `ctrl`：控制输入；
- `time`：当前仿真时间。

## 推进一步

```python
mujoco.mj_step(model, data)
```

每调用一次，MuJoCo 根据当前状态和控制输入推进一个时间步，并修改 `data`。

如果 MJCF 中：

```xml
<option timestep="0.002"/>
```

连续调用 10 次 `mj_step()` 后，`data.time` 应从 `0.0` 变为约 `0.02`。

### 练习：只推进时间

已有 `scene.xml`，要求：

1. 加载模型；
2. 创建 `MjData`；
3. 打印初始 `data.time`；
4. 调用 10 次 `mj_step()`；
5. 再打印 `data.time`。

已知接口：

```python
mujoco.MjModel.from_xml_path(path)
mujoco.MjData(model)
mujoco.mj_step(model, data)
```

若 `timestep="0.002"`，输出应接近：

```text
0.0
0.020000000000000004
```

浮点数最后几位可能略有不同。

<details>
<summary>参考实现</summary>

```python
import mujoco

model = mujoco.MjModel.from_xml_path("scene.xml")
data = mujoco.MjData(model)

print(data.time)

for _ in range(10):
    mujoco.mj_step(model, data)

print(data.time)
```

## 第一个可视化模型

[starter/01_falling_box](./starter/01_falling_box/) 中提供了一个地面和一个自由方块：

```text
地面
+
距地面 1 m 的方块
+
重力
```

运行：

```bash
cd starter/01_falling_box
python3 simulate.py
```

应看到方块下落并落到地面。

这里用到的 Viewer 接口：

- `mujoco.viewer.launch_passive(model, data)`：打开 Viewer；
- `viewer.is_running()`：窗口是否仍在运行；
- `viewer.sync()`：把当前 `data` 同步到画面。

完整示例先作为一个可运行程序观察。后面再逐步修改模型和控制。
