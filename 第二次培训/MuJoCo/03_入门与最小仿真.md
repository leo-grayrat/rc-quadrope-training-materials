# 入门与最小仿真

上一篇已经知道 falling box 和 single joint 的模型里有什么。现在开始让 Python 真正加载它们并推进仿真。

## MjModel 与 MjData

先加载 falling box：

```python
import mujoco

model = mujoco.MjModel.from_xml_path(
    "starter/01_falling_box/scene.xml"
)
```

`MjModel` 保存编译后的模型信息，例如刚体、关节、质量、惯量、碰撞几何、执行器和时间步长。这些结构和参数在一次正常仿真中大多保持固定。

然后创建：

```python
data = mujoco.MjData(model)
```

`MjData` 保存运行过程中会变化的状态和计算结果，例如当前位置、速度、控制输入和当前仿真时间。

可以先输出：

```python
print("nq =", model.nq)
print("nv =", model.nv)
print("nu =", model.nu)

print("qpos =", data.qpos)
print("qvel =", data.qvel)
print("ctrl =", data.ctrl)
print("time =", data.time)
```

这里：

- `model.nq`：位置状态 `qpos` 的长度；
- `model.nv`：速度状态 `qvel` 的长度；
- `model.nu`：控制输入 `ctrl` 的长度；
- `data.qpos`：当前位置状态；
- `data.qvel`：当前速度状态；
- `data.ctrl`：当前控制输入；
- `data.time`：当前仿真时间。

falling box 有一个 free joint，没有 actuator，所以刚创建 `MjData` 时应看到类似：

```text
nq = 7
nv = 6
nu = 0
qpos = [0. 0. 1. 1. 0. 0. 0.]
qvel = [0. 0. 0. 0. 0. 0.]
ctrl = []
time = 0.0
```

这里的 `7` 和 `6` 已经可以用上一篇的 free joint 结构解释，不需要把它们当成需要记住的 MuJoCo 数字。

## mj_step：让仿真向前走一步

MuJoCo 用：

```python
mujoco.mj_step(model, data)
```

推进一个物理时间步。

falling box 中已经写了：

```xml
<option timestep="0.002" gravity="0 0 -9.81"/>
```

因此每调用一次 `mj_step()`，仿真时间增加约 `0.002 s`，同时方块的位置和速度也会根据重力发生变化。

## Viewer：把当前状态显示出来

MuJoCo 的物理计算不依赖 Viewer。Viewer 只负责把当前状态画出来。

完整 falling box 示例：

- [starter/01_falling_box/simulate.py](./starter/01_falling_box/simulate.py)

核心结构是：

```python
with mujoco.viewer.launch_passive(model, data) as viewer:
    while viewer.is_running():
        mujoco.mj_step(model, data)
        viewer.sync()
```

其中：

- `mujoco.viewer.launch_passive(model, data)` 创建 Viewer；
- `viewer.is_running()` 判断窗口是否仍然打开；
- `mujoco.mj_step(model, data)` 推进物理状态；
- `viewer.sync()` 把新的状态同步到窗口。

运行：

```bash
cd starter/01_falling_box
python3 simulate.py
```

应该看到方块从空中落到地面。

示例中的 `time.sleep()` 只是让显示速度大致接近真实时间，不负责物理计算。

## 再看 single joint

现在加载上一篇已经看懂结构的单关节模型：

```python
model = mujoco.MjModel.from_xml_path(
    "starter/02_single_joint/scene.xml"
)
data = mujoco.MjData(model)

print(model.nq)
print(model.nv)
print(model.nu)
print(data.qpos)
print(data.qvel)
```

这个模型只有一个 hinge joint，也没有 actuator，所以应得到类似：

```text
1
1
0
[0.]
[0.]
```

对应关系很直接：

```text
joint1 当前角度     → data.qpos[0]
joint1 当前角速度   → data.qvel[0]
```

## 手工改变初始状态

如果希望仿真一开始就让 `joint1` 转过一定角度，可以直接修改：

```python
data.qpos[0] = 0.5
```

然后调用：

```python
mujoco.mj_forward(model, data)
```

`mj_forward()` 会根据修改后的状态重新计算模型的运动学和其他相关量，但不会推进仿真时间。
