# 排错与后续

## import 失败

```text
ModuleNotFoundError: No module named 'mujoco'
```

检查：

```bash
which python3
python3 -m pip show mujoco
```

确认运行脚本的 Python 与安装 MuJoCo 的 Python 是同一个环境。

## XML 无法加载

优先看 MuJoCo 报出的文件和位置，检查：

- XML 标签和属性；
- include 路径；
- mesh 路径；
- 被引用的 joint、body、asset 名称。

## mesh 找不到

```bash
pwd
find . -name "*.stl"
find . -name "*.STL"
find . -name "*.obj"
```

再与 `meshdir` 和 `file` 路径比较。

## 机器人直接掉下去

检查：

- 是否有 free joint；
- 初始 base 高度；
- 初始腿部角度；
- 地面是否存在。

零力矩下站立机器人失去支撑后下落属于正常结果。

## 剧烈抖动或弹飞

先保持：

```python
data.ctrl[:] = 0.0
```

再检查：

- 初始穿模；
- 碰撞体；
- 质量和惯量；
- joint range；
- 接触参数。

## ctrl 改了但没反应

检查：

```python
print(model.nu)
print(data.ctrl)
```

再确认 actuator 是否真的指向预期 joint。

## 调试时常看的量

```python
print("time:", data.time)
print("qpos:", data.qpos)
print("qvel:", data.qvel)
print("ctrl:", data.ctrl)

print("nq:", model.nq)
print("nv:", model.nv)
print("nu:", model.nu)
```

每次先确认一个问题，再进入下一层。

## 本阶段应掌握

完成后应能：

1. 加载 MJCF 并创建 `MjData`；
2. 用 `mj_step()` 推进仿真；
3. 看懂基本的 body、joint、geom、actuator；
4. 读取 `qpos`、`qvel`、`ctrl`；
5. 根据名字找到 joint；
6. 建立平地场景；
7. 配置 motor actuator；
8. 在零力矩下完成机器狗趴卧仿真；
9. 根据报错、模型和状态量排查基础问题；
10. 从主流程开始阅读 `unitree_mujoco`。
